# PageMind store assets

- `pagemind-small-promo.png`: required Chrome Web Store small tile, 440×280
- `pagemind-marquee-promo.png`: optional marquee tile, 1400×560

Both assets were generated with the built-in ImageGen workflow using
`src/assets/img/pagemind-icon-master.png` as the exact character reference, then resized to the
official pixel dimensions. The prompts requested a text-free, logo-free glossy 3D scene connecting
the PageMind character with abstract webpage, video, PDF, and local-memory elements.

The final installed beta still needs five real 1280×800 product screenshots. Do not substitute
generated UI for those screenshots.
