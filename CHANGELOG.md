# Changelog

All notable PageMind changes are documented here.

## 0.1.0 — Unreleased beta

- Rebuilt the extension around a unified Side Panel for webpages, YouTube, and PDFs.
- Added OpenAI, Gemini, Anthropic, and OpenAI-compatible/local chat providers.
- Added independent local or remote embedding configuration and hybrid retrieval.
- Added local page memory, content retention controls, and per-item data management.
- Added prompt buttons, citations, Markdown export, cancellation, progress, and resumable indexing.
- Added English and Korean localization, stable user-facing errors, and privacy disclosures.
- Added optional-origin validation, a self-only CSP, and lifecycle cleanup for PDF processing.
- Added deterministic tests and packaging for the Chrome beta.
